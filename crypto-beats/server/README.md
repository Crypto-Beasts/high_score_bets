# Crypto Beats Multiplayer Server (Colyseus)

Phase 2: Migrated to Colyseus for better state synchronization and scalability

## Setup

1. Install dependencies:
```bash
cd server
npm install
```

2. Start the server:
```bash
npm start
```

Or for development with auto-reload:
```bash
npm run dev
```

## Configuration

The server runs on port 2567 by default (Colyseus standard port). You can change this by setting the `PORT` environment variable:

```bash
PORT=2567 npm start
```

## Client Configuration

Update the client to connect to your server by setting the environment variable:

```bash
VITE_SERVER_URL=ws://localhost:2567
```

Or in your `.env` file:
```
VITE_SERVER_URL=ws://localhost:2567
```

Note: Colyseus uses WebSocket protocol (ws://) instead of HTTP.

GET /health

```
GET /info
```
Returns server version, phase, and active rooms.

## Colyseus Room

The server uses a Colyseus room called `game_room` with the following state:

### Room State Schema
- `players`: Map of player session IDs to player data (score, combo, finished status, etc.)
- `status`: Room status (waiting, starting, playing, finished)
- `song`: Selected song
- `difficulty`: Selected difficulty
- `startTime`: Synchronized game start time
- `roomId`: Room identifier

### Client Messages

#### Client → Server
- `scoreUpdate` - Send score/combo updates
- `playerInput` - Send player input for spectator view
- `gameEnd` - Notify game completion with final stats

#### Server → Client
- `opponentInput` - Opponent's input (for spectator view)
- `opponentFinished` - Opponent finished the game
- `matchComplete` - Match finished with results

### State Synchronization

Colyseus automatically synchronizes room state to all clients. When a player's score or combo changes, all clients receive the update automatically through state synchronization.

## Testing

1. Start the server
2. Open two browser windows
3. In window 1: Click "Multiplayer" → "Create Room"
4. In window 2: Click "Multiplayer" → "Join Room" (enter room ID)
5. Both players should see countdown and start playing

## Troubleshooting

- **Connection failed**: Make sure server is running and port 2567 is accessible
- **Room not found**: Room IDs are generated by Colyseus. Make sure you're using the correct room ID format
- **CORS errors**: Colyseus handles CORS automatically, but check if your client URL matches

## Migration Notes

This server was migrated from Socket.IO to Colyseus for:
- Automatic state synchronization
- Better room management
- Built-in reconnection handling
- Type-safe schemas
- Better scalability
